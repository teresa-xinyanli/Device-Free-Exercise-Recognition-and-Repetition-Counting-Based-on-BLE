# Windows interface

The desktop interface is self-contained in [`windows/`](windows/README.md).
This directory is maintained independently of the model/training code on `main`.
No root-level model files or project README are replaced by this interface snapshot.

For a ready-to-run Windows download, see the [interface preview release](https://github.com/teresa-xinyanli/Device-Free-Exercise-Recognition-and-Repetition-Counting-Based-on-BLE/releases/tag/interface-v0.3.1).
